## 4. Discussões e decisões

- Foram definidas as duplas e os tópicos do Documento de Visão pelos quais cada uma ficaria responsável.

- Foram discutidos os requisitos do produto:

    - **Back-end:** Python com FastAPI.
    - **Front-end:** JavaScript com Leaflet.
    - **Hospedagem:** Vercel.
- Foi definido o uso de Sprints semanais, programação em pares (*pair programming*), revisão de código (*code review*) pelo GitHub e dailies pelo WhatsApp.
- Foi elaborada a versão preliminar do Documento de Visão, seguindo o template disponibilizado.
