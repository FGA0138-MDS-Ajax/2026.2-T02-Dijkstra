# Sobre o Projeto

## 📌 Contexto e Motivação

O acesso a indicadores socioeconômicos confiáveis e atualizados é essencial para o diagnóstico social, o desenvolvimento de pesquisas acadêmicas e a tomada de decisões em políticas públicas. No entanto, esses dados costumam estar dispersos em diversas fontes governamentais e em formatos técnicos de difícil assimilação pelo público geral.

O **Brasil Hub** foi concebido para mitigar esse gargalo. A plataforma tem como missão centralizar, padronizar e democratizar o acesso a esses dados, oferecendo uma experiência interativa, acessível e visualmente intuitiva.

---

## 🎯 Proposta de Valor e Diretrizes

- **Centralização e Transparência:** Agrupamento de indicadores oficiais em um único repositório auditável.
- **Visualização Espacial:** Mapeamento geográfico interativo das 27 unidades federativas brasileiras via Leaflet.
- **Análise Comparativa:** Ferramentas para contraste direto entre estados, regiões e evolução temporal.
- **Integridade dos Dados:** Validação rigorosa dos dados importados; dados ausentes são tratados de forma explícita e nunca mascarados como zero.

## 🔄 Organização e Dinâmica de Engenharia

Para garantir produtividade, qualidade de código e alinhamento contínuo, a equipe adota:

- **Desenvolvimento em Duplas:** Distribuição de frentes técnicas (Back-end/Infra e Front-end) entre pares de desenvolvedores.
- **Revisão Cruzada Obrigatória (Code Review):** Nenhum código é integrado à branch `developer` sem aprovação de ao menos um revisor de outra dupla.
- **Ritos Ágeis:** Sprints semanais, reuniões de planejamento, dailies de acompanhamento e retrospectivas orientadas a métricas (GQM).
