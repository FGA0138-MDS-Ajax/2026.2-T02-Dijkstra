# Brasil Hub - Front-end Local

## Como executar o projeto localmente:
1. Certifique-se de ter um navegador moderno instalado (Chrome, Firefox ou Edge).
2. Clone o repositório ou acesse a pasta `src/frontend/`.
3. Abra o arquivo `index.html` diretamente no seu navegador, ou utilize uma extensão de servidor de desenvolvimento local (como o **Live Server** no VS Code) para evitar problemas de política de CORS com a API FastAPI.
4. Certifique-se de que a API FastAPI de back-end está rodando localmente na porta `8000`.
